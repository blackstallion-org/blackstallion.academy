# Audio assets (all optional; the site stays silent and works without them)

Sound is OFF by default and only plays after the visitor presses SOUND in the nav.

| File | Used for | Status |
| --- | --- | --- |
| bsah_ambient_432hz_drone.mp3 | Looping ambient bed (nav toggle) | needs a licensed or generated file |
| bsah_stallion_breath.wav | Breath cue at Reel 01, Reel 04, Act III divider | needs a licensed or generated file |
| bsah_keystroke.wav | Faint mechanical key sound in the Command Terminal | needs a licensed or generated file |

Confirm the licence of every file before launch (Blueprint Part 8 asset check).
