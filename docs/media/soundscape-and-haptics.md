```text
===================================================================

AUDIO SOUNDSCAPE & HAPTIC DIRECTIVES FOR WEB & MOBILE APP

===================================================================

1. Web Platform Audio Engine (Hero Section Toggle)

- Sound Control: Subtle gold audio toggle in the top-right header with 3 states:

* State A (Default): Mute.

* State B (Atmospheric Focus): 432Hz ambient binaural pad with distant arena soundscape.

* State C (Equestrian Rhythm): Slow, rhythmic turf trotting audio loop with faint cavalry bell accents.

2. Mobile App Haptic Feedback Triggers

- Heavy Impact Haptics (HapticFeedback.heavyImpact()): Triggered when an instructor stamps a milestone, validates a passport entry, or logs an official grade.

- Light Selection Haptics (HapticFeedback.selectionClick()): Triggered on tab switches and date picker selections.

- Success Pattern (HapticFeedback.notificationOccurred(Success)): Triggered when an autopay mandate or tuition receipt is confirmed.
```
