# Logo Usage Directives

> Source: `instructions/01_Logos/logo_directives_for_sting.txt.docx` (converted to Markdown for Claude Code; the original file is unchanged).

Logo Usage Directives for Sting Raj:

- Primary Header/Favicon: Synthesize dark-theme transparent SVG assets directly from stpci_medallion_crest.png and bsah_cover_page.jpg.

- Parent Emblem: Vicarius Mobius Emblem (vicarius_mobius_emblem.svg) will be rendered in pure gold (#C5A059) on holding-related components.

- Custom UI Glyphs: Extract the horse head and double lance vectors from the crest to use as SVG section dividers (⚜ ⚔ ⚜).
